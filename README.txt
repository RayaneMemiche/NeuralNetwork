# ♟️ Neural Network for Chess Analysis

This project implements a **Multilayer Perceptron (MLP)** to analyze chess games and predict the outcome based on specific board positions. The goal is to train a neural network capable of evaluating whether a given position is likely to lead to a win or a loss for the white player.

---

## 🚀 Features

- Evaluate chess positions using a trained MLP neural network  
- Predict whether a given board state favors white or not  
- Train custom neural network models on your own dataset  
- Test and compare different architectures and hyperparameters  
- Lightweight, fast, and easy to use from the command line

---

## 🛠️ Prerequisites

- Python 3.x  
  You can download and install it from the [official Python website](https://www.python.org).
